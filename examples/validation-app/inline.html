Cognitive3D WebXR SDK Validation — Inline (desktop / mobile, no XR)

Loads the real SDK from ../../lib/c3d.umd.js and starts a session with startSession(null). That still captures every non-XR raw device signal (user agent, UA brands/mobile, touch/pointer/hover media queries, device memory, GPU) — it only skips gaze tracking. See README.md for setup and the full scenario matrix.
