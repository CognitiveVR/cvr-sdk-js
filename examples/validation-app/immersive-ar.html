Cognitive3D WebXR SDK Validation — Immersive AR

Requests a real immersive-ar XRSession and starts a session with startSession(xrSession), capturing c3d.device.xr.input_profiles, XR session mode ('immersive-ar'), and reference space ('local'). See README.md for setup and the full scenario matrix.

Passthrough hardware required: this only works on devices with camera passthrough (e.g. Meta Quest 3 / 3s, Samsung Galaxy XR, Apple Vision Pro). Non-passthrough headsets (Quest 2, HTC Vive, ...) will report "immersive-ar" as unsupported below.
